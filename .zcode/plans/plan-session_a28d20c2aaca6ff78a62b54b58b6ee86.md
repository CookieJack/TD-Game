# 英雄暴击系统实现计划

## 需求
- 所有英雄攻击有 15% 概率触发暴击，暴击伤害 = 普通伤害 × 2
- 显示伤害效果：所有命中都弹出伤害数字，暴击为大号红色「暴击 ×N」

## 现状关键事实
- 4 位英雄（法师/猎人/圣骑士/牧师）的直接伤害统一经过 `damageEnemy()`（js/main.js:498），在此掷骰即可覆盖三者，溅射/AoE 中每个敌人独立判定
- 牧师特殊：暗影弹命中后挂 5 秒 DoT（js/main.js:793），不走 `damageEnemy`，需单独处理
- 已有 `FX.floatText(pos, text, color, size)` 飘字系统（js/effects.js:384，sprite + canvas 文字，带黑描边），直接复用
- 牧师光环是伤害加成倍率（非直接伤害）、猎人毒是附加 DoT、DoT 逐跳结算均不参与暴击掷骰（避免连续跳字刷屏）

## 改动内容

### 1. js/config.js — 新增暴击配置分节（放在 FX 分节附近，约 209 行前）
```js
// ============ 暴击（英雄攻击命中时概率造成倍率伤害） ============
CRIT: { chance: 0.15, mult: 2 },
```

### 2. js/main.js `damageEnemy`（498-504 行）— 暴击掷骰 + 通用伤害飘字
- 进入时掷骰 `Math.random() < CFG.CRIT.chance`，暴击则 `amount *= CFG.CRIT.mult`
- 显示实际扣血数（护甲减免后，四舍五入）：
  - 普通命中：小号白色数字 `N`（size ≈ 0.8），带轻微随机横向偏移避免溅射多目标数字重叠
  - 暴击：大号红色 `暴击 N`（'#ff4a2a'，size ≈ 1.5）+ 敌人位置一小簇红色 `FX.burst` 增强打击感
- 飘字位置在敌人头顶（mesh.position 基础上加约 +0.9），与击杀时金色 `+分数` 飘字颜色区分（金色=得分、白色=伤害、大红=暴击）

### 3. js/main.js 牧师 onHit（792-795 行）— DoT 攻击的暴击
- 命中时同样掷暴击骰，暴击则 DoT 总伤害翻倍：`dps: (lv.dot * mult * CFG.CRIT.mult) / 5`
- 与其他英雄一致显示飘字：普通显示 DoT 总伤害数字，暴击显示大号红色 `暴击 N`

### 4. js/effects.js — 无需改动（floatText 已支持颜色/字号参数）

## 验证（按 IAB 测试技巧记忆）

4. 分别观察法师溅射多目标（各敌独立飘字）、圣骑士 AoE、牧师 DoT 攻击的飘字表现，确认控制台无报错
