# 英雄经验升级 + 圣光动画 + 技能成长 + 减速表现 实施计划

## 现状结论（已核实）
- 英雄=塔（`main.js:144-159`），等级存于 `Game.heroLevels`，上限 4 级；目前只能在关卡结算界面花积分手动升级（`main.js:170-187`）。
- 无经验概念，积分（🏅）唯一用途是升级 → 改造后保留为战绩分数。
- 法师寒冰箭减速目前 100% 触发（`main.js:543-547`），怪物被减速只有头顶小蓝点（`main.js:327-330`），本体无任何表现。
- `FX` 已有粒子/光柱/冲击环/点光池（`effects.js`），现有光柱是"贴地升起"，需新做"从天而降"光柱。
- `MatCache`（`world.js:2-14`）材质全局共享 → 怪物染色前需按个体克隆材质。

## 已确认的设计决策
1. **经验分配**：击杀者获得（每次伤害记录来源英雄，DoT 击杀归牧师）。
2. **升级方式**：经验条满**自动升级**，圣光即刻降临，无需点击。
3. **积分**：保留为战绩分数展示，不再消耗。
4. 等级上限保持 4 级；减速触发率 L1→L4 = 10%/15%/20%/25%（封顶 25%，config 可调）。

## 改动明细

### 1. js/config.js — 数值层
- 新增 `CFG.XP = { need: [180, 380, 700] }`（升到 2/3/4 级所需经验，调优旋钮）。
- `ENEMIES` 每种怪物加 `xp` 字段（初值=points：8~330，boss 高经验）。
- 法师 4 级 `levels` 各加 `slowChance: 0.10/0.15/0.20/0.25`（注释标明封顶 25%），`statLine` 增加"触发 xx%"。
- 每个英雄加 `fx` 数组（4 级各一档）：`{ color, boost }`——弹道/粒子/点光颜色随级变亮变纯（如 mage `0x7fc8ff→0xd8f4ff`），`boost` 放大弹道体积/光强/粒子数（1.0→1.5）。射程本就随级增长（config `levels.range`），选中光环自动跟随。
- 删除各英雄 `upgrades` 积分花费数组及 `START_POINTS` 相关注释。

### 2. js/effects.js — 特效层
- **`FX.holyBeam(pos, colorHex, opts)`**（新）：专用对象池（3 根高约 9 的加色开口圆柱），三阶段动画：①天而降（0~25%：光柱顶端固定于天上、底端向下延伸触及英雄）②照耀（25~70%：全柱脉冲、金色点光照亮英雄、金色粒子上升、地面金环扩散）③消散（70~100%：透明度归零、圣光消失）。总时长约 1.8s，`update()` 加对应分支。
- **`FX.snowTexture()`**（新）：canvas 画六角雪花纹理，供减速图标用。
- `FX.projectile()` 支持 `opts.color`/`opts.scale`（弹体与光晕随等级放大，拖尾颜色跟随），不改默认行为。

### 3. js/main.js — 逻辑层
- **经验系统**：`state` 加 `heroXp: {mage:0,...}`；`damageEnemy(e, amount, src)` 与 `_killEnemy(e, src)` 增加来源参数（mage 溅射/hunter 直击/paladin 冲击在 `_releaseShot` 传入，牧师 DoT 条目加 `src:'priest'`，`_updateEnemies` DoT 结算带回）。`_grantXp(type, xp)`：累加 → 满 `CFG.XP.need` 则升级（循环处理溢出经验结转），调用 `_levelUpHero`。
- **自动升级 `_levelUpHero(type)`**：由 `upgradeHero` 改造，去掉积分判断/扣除；`heroLevels++`、重建模型、播放**圣光天降**（`FX.holyBeam` + 金粒子 + 冲击环 + `floatText('⬆ 升级！')` + upgrade 音效）、toast、刷新 UI 与 3D 经验条。
- **技能光影随级增强**：`_updateTowers` 施法点光与 `_releaseShot` 中所有硬编码色值（0x8fd8ff 等）改为查 `CFG.TOWERS[type].fx[level-1]`；粒子数/光强/光斑半径乘 `boost`。
- **减速触发率**：法师命中循环内伤害必结算，减速改为 `Math.random() < lv.slowChance` 判定后调 `_applySlow(e, lv)`（原 slowUntil/slowFactor 逻辑移入），仅触发时附带一小簇冰粒爆散让"触发"可辨识。
- **减速本体表现**：
  - `_spawnEnemy` 给敌人记录 `animT`（初值=animOffset）；`_updateEnemies` 改 `e.animT += eff * dt` 并传给 `anim()` → 减速时步态变慢、眩晕时定格。
  - 首次被减速时 `_ensureOwnMaterials(e)`：遍历克隆该怪物全部材质并记录原始色；染色为冰蓝（color 向 0x9fd4ff 混合约 45% + 微量 emissive），减速结束/死亡恢复原色。
  - `slowIcon` 换成雪花纹理精灵并放大，激活时缩放脉冲；减速期间每 ~0.45s 冒 1-2 粒冰晶粒子。
- **3D 经验条**：`_spawnTowerMesh` 在英雄头顶加血条式经验条（暗底+金色填充 Sprite，同敌人血条做法）；`_grantXp`/升级时更新；经验满时轻微脉冲提示。

### 4. js/ui.js + index.html + css — 展示层
- 塔面板（`index.html:36-47`）加经验条行（`#tp-xp-bar`+`#tp-xp-text`），`showTowerPanel` 填充当前经验/所需。
- `_renderSquad` 移除升级按钮与积分判断，卡牌上加经验条+等级星；`showLevelScreen` 副标题改为"英雄凭战斗经验自动升级"，仍显示 🏅 战绩积分。
- `css/style.css` 补经验条样式（复用面板金色主题）。

## 实施顺序
config → effects → main（经验/升级 → 技能成长 → 减速表现）→ UI/HTML/CSS → 浏览器实测调参。
