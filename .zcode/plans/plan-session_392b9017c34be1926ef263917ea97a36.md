# 3D 魔兽风网页塔防游戏 — 实施计划

## 技术方案（已确认）
零依赖、双击即玩：`index.html` + 普通 `<script>` 标签分模块加载 + 本地下载 `three.min.js`（three@0.147 UMD 版，含 CapsuleGeometry）。全程离线可玩，无需 Node、无需服务器、无需联网。相机控制（拖拽旋转 / 滚轮缩放 / 右键平移）自行实现约 40 行代码，不额外引 OrbitControls。

## 文件结构
```
TD-Game/
├── index.html          # 页面骨架 + 魔兽风格 UI 层
├── css/style.css       # 金色边框/羊皮纸质感 UI、血条、卡牌样式
└── js/
    ├── three.min.js    # 本地 Three.js（下载）
    ├── config.js       # 数值配置：塔/敌人/波次/经济
    ├── utils.js        # 工具函数、简易相机控制
    ├── world.js        # 场景：地形、路径、树石装饰、黑暗之门、城门
    ├── characters.js   # 4 位英雄 + 各类敌人的低多边形程序化建模
    ├── effects.js      # 弹道、粒子、光柱、飘字特效
    ├── audio.js        # Web Audio 合成音效（可静音）
    ├── ui.js           # HUD、建造卡牌、塔面板、结算界面
    └── main.js         # 游戏状态机 + 主循环
```

## 玩法设计
- **地图**：低多边形草地，一条蜿蜒石板路从「黑暗之门」（发绿光的传送门）通向「暴风城大门」。路径两侧有发光的建造基座（约 10 个），树木岩石点缀。敌人到达城门扣 1 点城堡生命，共 20 点。
- **经济**：初始 250 金币，击杀掉金 + 飘字提示。
- **波次**：共 20 波，波间隔可点按钮立即召唤（奖励金币）。每 5 波精英/Boss：第 10 波巫妖、第 15 波深渊火魔王、第 20 波最终 Boss 巫妖王。胜利/失败结算画面，可重开。
- **4 位英雄塔**（快捷键 1-4 选中 → 点击基座建造）：
  | 英雄 | 定位 | 攻击方式 | 特性 |
  |---|---|---|---|
  | 亡灵法师 | 范围输出 | 寒冰箭（弹道） | 溅射伤害 + 减速敌人 |
  | 暗夜精灵猎人 | 快速单体 | 箭矢 | 攻速最快、射程最远 |
  | 人类圣骑士 | 近战清场 | 奉献圣光冲击波 | 自身周围圆形范围伤害 + 短暂眩晕 |
  | 血精灵牧师 | 辅助 | 暗言术：痛（持续伤害） | 暗影光环：提升周围友军 25% 伤害 |
- **升级/出售**：每塔 3 级（数值与外观增强，模型变大/加特效），出售返还 70%。
- **敌人**：鱼人（快）、野猪、食尸鬼、兽人步兵（重甲）、石像鬼（亡灵蝙蝠，快而脆）、精英巫妖、Boss×3。头顶血条，受击闪红、减速变蓝、牧师 DoT 挂暗影标记。
- **操作**：左键点选/建造，滚轮缩放，左键拖拽旋转视角，右键平移；1x/2x 变速、暂停、音效开关。

## 视觉与音效
- 角色全部用 Three.js 几何体拼装的低多边形小人：亡灵法师（苍白骨色+深蓝法袍）、暗夜精灵（紫肤+绿甲+弓）、圣骑士（金银重甲+盾+锤）、血精灵牧师（红白法袍+金发）；种族配色准确，塔基座带职业色光环。
- 光照：平行光 + 半球光 + 阴影；黑暗之门粒子漩涡、圣骑士奉献金圈、冰霜减速粒子等小特效。
- UI 魔兽风：金色雕纹边框、底部英雄卡牌栏（头像色块+价格+冷却遮罩）、顶部金币/生命/波次条。
- 音效用 Web Audio 现场合成（射击、命中、建造、金币、波次号角、失败/胜利），无音频文件。
