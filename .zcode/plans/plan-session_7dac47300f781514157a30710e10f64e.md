# 相机改城墙斜上空 + 英雄城墙一字排开

**现状**:相机在 +z 侧俯瞰全图(main.js:38);12 个建造基座散布地面(config.js:17);暴风城城墙在东缘 x=24.2,墙顶面 y=6.2,门洞两侧各一段墙(z∈[±2.0,±8.8],端头被门楼角楼占去约 1.4)。

**目标**:初始机位停在城墙斜上空、朝西俯瞰来敌方向;全部英雄站位改为墙顶一排 10 个(门洞两侧各 5 个),面朝西侧战场。射程整体 ×2(已确认)。

## 1. config.js(数值集中)
- `CFG.PLOTS` 改为 10 个 `[x, y, z]` 城墙顶站位:x=24.4、y=6.2,z=±{2.45, 3.55, 4.65, 5.75, 6.85}(避开门柱 z=±2.2 与角楼,间距 1.1)。
- 新增 `CFG.CAMERA = { target: [18, 2, 0], theta: Math.PI/2, phi: 0.9, radius: 18 }` — theta=90° 使相机位于城墙东侧上空朝西看;实现时截图微调。
- `TOWERS` 各级 `range` ×2(法师 11/12.6/14.4,猎人 14/16/18.4,圣骑 5.4/6.2/7.2,牧师 10/11/12;`auraRange` ×2 至 8/9/10 让光环覆盖整面城墙;法师 `splash` 是爆炸半径,不动)。

## 2. world.js
- `_plots`:pad/金环搬到墙顶(pad 缩为 r≈0.62 石台,y=6.29;环 y=6.4),plot 对象增加 `y` 字段。
- `_stormwindGate`:城垛让出墙顶站立空间 — 尺寸 (2.0,0.7,0.8)→(0.9,0.7,0.8)、局部 x 0→-0.45(移到迎敌侧边沿);墙体加 `receiveShadow` 承接英雄投影。
- `_decor` 避让判断改读 `p[0]`/`p[2]`(适配 [x,y,z])。

## 3. main.js
- 相机初值(main.js:38-39)改读 `CFG.CAMERA`。
- `_spawnTowerMesh`:`group.position.set(x, plot.y, z)` + `group.rotation.y = -Math.PI/2`(英雄面向西侧来敌)。
- 幽灵预览:位置 y 用 `plot.y`、朝向同上;ghostRange/选中光环仍贴地面 y=0.09(在地表显示真实覆盖范围)。
- 弹道起点(main.js:496):y = `plot.y + 原枪口高度`。
- 建造/升级/出售特效与圣骑士奉献圈的 y 提升 `plot.y`(圣骑伤害判定本就用 XZ 距离,不改)。
- `_faceHead` 补偿组朝向:`atan2(dx,dz) - tower.group.rotation.y`。
- 提示文案改为"点击城墙上的发光基座建造"。
