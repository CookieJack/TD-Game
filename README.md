# 王城保卫战 — 3D 网页塔防

西方奇幻题材的 3D 塔防游戏。敌人从**传送门**涌出，沿蜿蜒山路进攻**王城大门**。
四位英雄驻守城墙顶一字排开，抵御 **4 个关卡共 20 波**进攻，最终击败**亡灵之王**！

## 运行方式

**零依赖，双击即玩**：直接用 Chrome / Edge / Safari 打开 `index.html` 即可，无需安装、无需联网。

> 也可以在本目录起一个静态服务器后访问，例如：
> `python3 -m http.server 8377` → http://localhost:8377

## 玩法

- 开局进入**英雄布阵**：四位英雄默认站上城墙 4 个坑位，点击两张卡牌交换站位后开战
- 敌人到达城门扣 1 点城堡生命（共 20 点），归零即失败；顶住全部 4 关即胜利
- 击杀敌人与打退波次获得**积分**；每波之间自动倒计时，**提前召唤下一波可获得奖励积分**
- 每关（5 波）打完自动暂停进入**关卡结算**：展示英雄技能 / 射程卡牌，用积分升级英雄、可继续交换站位，再开启下一关
- 每 5 波有精英/Boss：第 10 波巫妖、第 15 波深渊火魔王、第 20 波亡灵之王

### 四关场景与多路进攻

| 关卡 | 场景 | 战场 | 路线 |
|---|---|---|---|
| 第一关 · 兽人先锋 | 翠绿林地 | 晨光松林，偶有阵雨 | 西路 1 条 |
| 第二关 · 亡灵大军 | 暮色沼泽 | 毒雾泥沼，常下暴雨 | 西 + 北 2 条 |
| 第三关 · 恶魔军团 | 霜雪平原 | 大雪纷飞，暮色入夜 | 西 + 北 + 南 3 条 |
| 第四关 · 亡灵之怒 | 冰封之地 | **永夜**暴雪，能见度极低 | 3 条 |

- 每条路线各有一座**传送门**（西 / 北 / 南），敌人兵分多路涌向王城大门；换关时战场随主题整体重建
- **昼夜循环**（约 150 秒一天）：太阳/月亮绕场转动、天空雾色渐变、夜晚星光与火炬更亮
- **天气**每波随机（晴 / 雨 / 雪 / 暴雪 / 雾，按关卡天气池抽取）：雪天地面怪减速（飞行单位不受影响）、雨天塔射程微降、雾/暴雪能见度骤降、雨天有闪电；数值均可在 `config.js` 的 `CFG.WEATHER` 调节

### 四位英雄（各 4 级成长）

| 英雄 | 定位 | 特性 |
|---|---|---|
| ❄️ 亡灵法师 | 范围输出 | 寒冰箭溅射伤害 + 减速 |
| 🏹 精灵猎人 | 快速单体 | 攻速最快、射程最远 |
| ⚔️ 人类圣骑士 | 近战清场 | 奉献冲击波 + 眩晕 |
| ✨ 精灵牧师 | 暗影辅助 | 暗影侵蚀 + 光环提升友军伤害 |

- 英雄等级在关卡结算界面用积分升级（★→★★★★），等级与阵容全程保留
- 牧师光环范围内的友军伤害提升

### 操作

| 操作 | 效果 |
|---|---|
| 点击两张卡牌 | 交换英雄站位（布阵 / 关卡结算界面） |
| 点击城墙上的英雄 | 查看面板：等级 / 技能 / 射程 |
| 左键拖拽 | 旋转视角 |
| 右键拖拽 | 平移视角 |
| 滚轮 | 缩放 |
| 空格 | 召唤下一波 |
| P / ⏸ | 暂停 |
| T | 调试：时刻快进 4 小时（看昼夜变化） |
| W | 调试：切换天气 |
| Esc | 取消选择 |

## 技术

- Three.js r147（本地 `js/three.min.js`，UMD 版）
- 全部角色为程序化低多边形建模（无外部模型/贴图/音频文件）
- 音效由 Web Audio 实时合成
- 代码结构：`config`（数值：经济 / 关卡 / 路线 / 场景主题 / 昼夜 / 天气） / `world`（场景，按关重建） / `characters`（建模） / `effects`（特效） / `environment`（昼夜与天气） / `audio` / `ui`（布阵与结算界面） / `main`（状态机与主循环）
