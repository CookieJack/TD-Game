# 艾泽拉斯守护战 — 3D 网页塔防

仿魔兽世界题材的 3D 塔防游戏。敌人从**黑暗之门**涌出，沿蜿蜒山路进攻**暴风城大门**。
四位英雄驻守城墙顶一字排开，抵御 **4 个关卡共 20 波**进攻，最终击败**巫妖王**！

## 运行方式

**零依赖，双击即玩**：直接用 Chrome / Edge / Safari 打开 `index.html` 即可，无需安装、无需联网。

> 也可以在本目录起一个静态服务器后访问，例如：
> `python3 -m http.server 8377` → http://localhost:8377

## 玩法

- 开局进入**英雄布阵**：四位英雄默认站上城墙 4 个坑位，点击两张卡牌交换站位后开战
- 敌人到达城门扣 1 点城堡生命（共 20 点），归零即失败；顶住全部 4 关即胜利
- 击杀敌人与打退波次获得**积分**；每波之间自动倒计时，**提前召唤下一波可获得奖励积分**
- 每关（5 波）打完自动暂停进入**关卡结算**：展示英雄技能 / 射程卡牌，用积分升级英雄、可继续交换站位，再开启下一关
- 每 5 波有精英/Boss：第 10 波巫妖、第 15 波深渊火魔王、第 20 波巫妖王

### 四位英雄（各 4 级成长）

| 英雄 | 定位 | 特性 |
|---|---|---|
| ❄️ 亡灵法师 | 范围输出 | 寒冰箭溅射伤害 + 减速 |
| 🏹 暗夜精灵猎人 | 快速单体 | 攻速最快、射程最远 |
| ⚔️ 人类圣骑士 | 近战清场 | 奉献冲击波 + 眩晕 |
| ✨ 血精灵牧师 | 暗影辅助 | 暗言术：痛 + 光环提升友军伤害 |

- 英雄等级在关卡结算界面用积分升级（★→★★★★），等级与阵容全程保留
- 牧师光环范围内的友军伤害提升

### 操作

| 操作 | 效果 |
|---|---|
| 点击两张卡牌 | 交换英雄站位（布阵 / 关卡结算界面） |
| 点击城墙上的英雄 | 查看面板：等级 / 技能 / 射程 |
| 左键拖拽 | 旋转视角 |
| 右键拖拽 | 平移视角 |
| 滚轮 | 缩放 |
| 空格 | 召唤下一波 |
| P / ⏸ | 暂停 |
| Esc | 取消选择 |

## 技术

- Three.js r147（本地 `js/three.min.js`，UMD 版）
- 全部角色为程序化低多边形建模（无外部模型/贴图/音频文件）
- 音效由 Web Audio 实时合成
- 代码结构：`config`（数值：经济 / 关卡 / 英雄成长） / `world`（场景） / `characters`（建模） / `effects`（特效） / `audio` / `ui`（布阵与结算界面） / `main`（状态机与主循环）
